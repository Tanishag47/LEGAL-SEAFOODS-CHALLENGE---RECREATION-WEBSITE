<h3>🦞 Inspiration for the Project</h3>
<p>The goal of this project was to recreate the Legal Sea Foods website while exploring how an established restaurant brand presents its identity, menu, and dining experience. 
  
  As a former Legal Seafoods server, one of my first web personal development projects came from something close to home. I studied the restaurants website, along side my own experience with the brand and I wanted to try to recreate it in my own way.</p><br><br>

***

<h3>🚀 Project Features</h3>

  - **Restaurant History:** Short Description of the Legal Seafoods legacy and history behind todays storefront locations.
  - **JavaScript Product Switcher:** An interactive display that allows user to click through to see the most popular dishes offered at restaurant locations.
  - **JavaScript Guessing Game:** Created an interactive guessing games for users to type in a number 1-10 for the opportunity to win a free lobster roll.

***

<h3>🔧 Tools & Technologies</h3>

| Tool | Purpose | 
| -------- | -------- | 
| HTML5  | Website structure and content | 
| CSS3  | Styling and layout design | 
| JavaScript  | Interactive functionality for guessing game and product switcher  |

***

<h3>🧠 What I Learned</h3>

- Improving my understanding of web organization, usability and visual/brand consistency.
- Furthering my understanding of JavaScript to increase functionality and engagement for users.
- The challenges of recreating an established brands identity through front-end development from my own lense.

***

<h3>🔮 Future Developments</h3>

- Improving the website with further usability features and important information, such as better branding, restaurant locator, full in-site menu and responsive design.
